# Contributing

1. Open an issue describing the task the skill helps with.
2. Add a self-contained folder under `skills/`.
3. Include a `SKILL.md` with clear activation conditions and a predictable workflow.
4. Add scripts only when they provide repeatable, testable functionality.
5. Include tests for scripts and document dependencies.
6. Never include credentials, private datasets, or personal data in examples.
7. Test the skill manually in a supported Claude environment before claiming compatibility.
